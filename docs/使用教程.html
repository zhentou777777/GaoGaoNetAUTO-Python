三十秒速览

如果你只想赶紧用上：

  1. 下载 GaoGaoNetAUTO.exe，双击运行
  2. 确保手机或电脑已连上校园网 Wi-Fi
  3. 点 「扫码登录」 → 用手机上的 糕糕 APP 扫一下 → 电脑上立刻就联网了

搞定。这一步不需要任何 Token、不需要抓包、也不需要配置。

之后想彻底不掏手机，再往下看第四节。

你要的功能：开机自启 + 断网重连

这是本工具的主功能。配好一次，之后完全不用管。

三步配置

  1. 设置区填账号密码 → 点「登录并保存」

（没有账号密码也行：扫码登录一次，把 Token 存下来）

  1. 勾选 「开机自动认证」 → 点「保存设置」
  2. 完事

之后它会自动做什么

场景 程序的动作
开机 注册表 Run 项静默启动 → 等 8 秒让网络就绪 → 自动认证上线
断网 / 换网络 守护线程每 20 秒探测一次；发现断网后指数退避持续重试（15s → 30s → 60s → 120s 封顶），一直到恢复
出口 IP 变化 校园网重新分配 IP 会让旧授权失效 → 检测到立即重新认证
Token 被服务端轮换 自动用账号密码换一个新 Token → 重新认证 → 存回本地
认证成功但外网还是不通 实测连通性，如实提示并继续重试（校园网 DNS 未生效的常见坑）

为什么"扫码登录"撑不过一晚上？

这是很多人会困惑的点，说清楚：

扫码只是让服务端把当前这一台设备放行一次。

这个会话有有效期，网络断了、或校园网那边会话超时，就得重来。

要真正做到"开机就连、断网自愈"，手里必须有一个能自己续期的 Token。

两种获得它的方式：

- 填账号密码（推荐）→ 程序自己去云高换一个，永久免抓包

- 抓一次包 → 手动存 Token，但 Token 失效时仍需重新抓

所以第四步的账号密码是关键，别跳过。

第一步：下载与运行

下载

前往 Releases 页下载：

https://github.com/zhentou777777/GaoGaoNetAUTO-Python/releases

下载 GaoGaoNetAUTO.exe（约 18 MB，单文件，免安装）。

运行

双击即可，不需要安装 Python、不需要解压、不需要改文件名。

首次运行如果 Windows 弹出「Windows 已保护你的电脑」：

  • 点「更多信息」→ 「仍要运行」
  • 这是 PyInstaller 单文件程序的正常提示，不是不安全

想看启动过程，可以在 exe 所在目录按住 Shift 右键 →「在此处打开 PowerShell 窗口」→ 输入：

```powershell

.\GaoGaoNetAUTO.exe

```

这样会多出一个黑色控制台窗口，里面能看到本地页面的地址。

界面在浏览器里

双击后程序会自动打开浏览器，界面是一个跑在 127.0.0.1 的本地网页 （地址形如 http://127.0.0.1:8765/?t=xxxx）。

  • 这个地址带一次性令牌，只在这台机器上有效，不要转发给别人
  • 地址栏里的 ?t=... 可以删掉 —— 删了也能用，程序已经在 Cookie 里记住了
  • 关掉浏览器页面不会退出程序，程序还在后台守着网络
  • 页面找不到了？地址也写在 %LOCALAPPDATA%\GaoGaoNetAUTO\webui.url，

或者直接右键托盘图标 →「打开界面」

托盘图标

界面在浏览器里，但程序本身常驻系统托盘（右下角小图标区域， 可能要拖到箭头里才看得到）。托盘图标右键菜单：

菜单项 作用
打开界面 重新打开浏览器页面（页面被关掉时用这个）
立即认证 立刻重新认证一次
退出 真正退出程序

第二步：先连上校园网

这一步很关键，必须先做，否则后面所有操作都会失败。

电脑连上校园网 Wi-Fi（或校园网网线），此时状态卡上会显示你的出口 IP，形如 10.135.130.202。

出口 IP 是云高用来标识「哪台设备」的凭据。程序每次运行都会自动重新探测，

所以你的 Windows 开了「随机硬件地址」也没关系，不需要为了这个工具去关闭 MAC 随机化。

如果出口 IP 是空的，说明还没连上校园网，或者网线/路由器不在校园网内网段。

第三步：扫码登录（第一次一定要做）

这是不依赖 Token 的路径，也是所有路径的基础。

操作

  1. 点网页上的 「扫码登录」
  2. 弹出一个二维码弹层，状态显示「正在获取二维码…」
  3. 几秒后二维码出现，用手机上的糕糕 APP 扫描
  4. 手机上点确认
  5. 电脑上状态变为绿点「在线」，日志显示已上线

二维码是怎么来的（了解原理更安心）

本工具不依赖服务端图片，二维码是在你电脑上本地生成的：

PC 访问 /web/network/code  →  服务端下发 Set-Cookie: str=<UUID>（会话标识，10 分钟有效）
                            ↓
              页面把二维码内容用 XOR 混淆内嵌在 JS 里
                            ↓
              本工具用同样的算法在本地还原出 UUID 并渲染成二维码

也就是说，二维码内容就是这次授权会话的 UUID，不经过任何第三方。

二维码过期了怎么办

10 分钟不扫就会失效。点二维码弹层里的 「刷新二维码」 重新生成一张即可。

关于"单设备只能登录一台"

PC 认证成功后，手机上的校园网会掉线。 这是学校账号「同时只能一台设备在线」的限制导致的，不是程序 bug。

想让手机也上，用网页上的 「归还名额」 按钮把位置让回给手机。

第四步：填账号密码，实现永久免手机

这是让"断网自动重连"真正能闭环的一步。

云高的登录接口

程序逆向出了云高统一用户中心的登录接口：

POST https://user.v4.yungao-tech.com/api/login
Content-Type: application/json

{"mobile": "<手机号>", "password": "<密码>"}

云高账号体系里，手机号就是登录名。

怎么填

  1. 网页设置区找到「账号密码」
  2. 填手机号和密码
  3. 点 「登录并保存」

日志出现这几行就说明成功了：

正在用账号密码登录云高…
★ 账号 138****8888 登录成功，Token 已保存（已加密）
账号密码已保存——以后 Token 失效会自动换新的，断网也能自愈

密码和 Token 用同一套加密方案（Windows DPAPI，系统级、用户绑定、随机 nonce）存在 %LOCALAPPDATA%\GaoGaoNetAUTO\config.json 里，文件里是密文，换一台电脑或换用户都解不开。

想抹掉本机保存的凭据：设置区底部点 「清除已保存凭据」（会二次确认），

Token / 上一版 Token / 手机号 / 密码会一并抹掉，备份文件也覆写删除。

不想在程序里填？先单独测一下

怕填错、或想知道云高是否认你的账号，可以先在命令行测（不会保存任何东西）：

python tools/login_check.py

它会交互式问你要手机号和密码（密码不回显、不进 shell 历史），然后打印服务端原始应答和错误分类。

也可以只把手机号写在命令行：python tools/login_check.py 13800138000 —— 密码仍然走交互输入。

不建议把密码也写进命令行：同机其他账号通过进程列表就能看到。

各种错误的含义

程序提示 含义 怎么办
账号不存在 该手机号在云高没注册 确认云高账号是不是手机号；不是的话改用下面的抓包方式
手机号格式不正确 手机号格式错 填 11 位手机号
密码错误 密码不对 检查一下
接口参数不匹配 云高改了登录接口 用抓包兜底
需要图形/短信验证码 该接口不支持直接登录 用抓包兜底

如果你的校园网账号是学号而不是手机号，「账号不存在」是正常的。

这时走下面的抓包方式拿 Token，功能一样，只是 Token 失效时需要手动重抓。

备用方案：抓包取 Token

实在填不了账号密码，还有这条路。

云高网页登录流程本身不带 Authorization 头，所以从浏览器 DevTools 复制这条路多半取不到。

Token 只存在于糕糕 APP 的网络流量里。

安卓抓包步骤

  1. 安卓手机安装 抓包精灵 或 HttpCanary（任选其一）
  2. 打开抓包工具 → 允许安装 CA 证书
  3. 抓包精灵：设置 → 证书安装 → 选「系统证书」（部分机型还要去系统设置里手动信任）
  4. HttpCanary：设置 → 证书 → 安装
  5. 开始抓包 → 打开糕糕 APP，等几秒让它产生网络请求
  6. 在抓包列表里按域名筛选。云高 APP 会访问这几个域名，带 Authorization 头的都在里面：
域名 说明
hgs.auth.yungao-tech.com 学校网关，最优先看这个
user.v4.yungao-tech.com 云高统一用户中心，/api/user 族需要 Token
h5pay.yungao-tech.com 支付相关，一般用不上

> 抓包工具显示「内容已隐藏」？ > 说明该域名没在解密域名列表里。详情页一般有个「添加此域名」按钮， > 点一下加进去就能看到请求头和响应体了（多数工具有 5 个免费名额，够用）。

> 最快的入口：找 hgs.auth.yungao-tech.com/api/network/auth 这条请求—— > 它的请求头就是标准格式的 Authorization: Bearer ...。 > 顺带一提，这条请求的响应体是 {"code":200,"msg":"认证成功。"}（36 字节）， > 说明你抓到的 Token 当时是有效的。

  1. 点开请求 → 请求头 / Request Headers → 找到 Authorization：

`` Authorization: Bearer eyJhbGciOi... ^^^^^^^^^^^^^^^^^ 从这里开始复制，到行尾为止 ``

  1. 回到电脑网页，把这串粘进 「Token」 输入框
  2. 点 「校验并保存」

程序会立刻拿这个 Token 去认证验证。验证通过会显示绿色的 Token 健康状态。

程序里的「怎么获取？」按钮

设置区 Token 输入框旁边有个 「怎么获取？」 按钮，点开就是这份图文步骤，不用回来翻教程。

如果抓包失败

提示证书固定（Certificate pinning）看不到明文？ 说明 APP 启用了 SSL Pinning。两条路：

  • 换用「抓包精灵」等带 SSL Unpinning 能力的工具
  • 放弃 Token，直接用「扫码登录」——那条路完全不需要 Token，功能不受影响

实在拿不到 Token 会怎样？ 程序会自动降级到扫码模式，每 10 分钟才需要你扫一次，其余时间靠自动重认证自愈。

第五步：设置开机自启

  1. 网页设置区勾选 「开机自动认证」
  2. 点 「保存设置」

程序会往注册表 HKCU\...\Run 写一项，之后开机自动运行并尝试认证。

想彻底卸载自启：取消勾选 → 保存设置，或者直接删掉 exe（注册表项建议用上面的方式清）。

网关地址怎么查？

学校发的校园网使用说明里，或者你在浏览器访问认证页面时看地址栏。

格式是 主机名:端口，端口通常是 1110。

想让手机和电脑同时上网（不挤掉手机）

学校的套餐通常只允许一台设备在线。服务端按出口 IP 记录在线设备， 所以 PC 认证会把手机挤下线。

方案 A：让电脑连手机热点（推荐）

两台设备共用同一个出口 IP，服务端就只看到"一台设备"：

手机连校园网 Wi-Fi  →  手机开热点  →  电脑连手机热点
                                          ↓
                        对外是同一个出口 IP，只需认证一次

这样手机和电脑同时在线，互不干扰。

程序会自动识别这种情况：认证前先查在线设备列表， 发现本机出口 IP 已经在列表里就直接判定"已在线"， 不会执行任何下线动作，所以不会把手机踢掉。

日志里会看到：共享模式：检测到本机已在线

方案 B：抢占上线（电脑主动接管）

想让电脑独占、把手机踢下线时，点主窗口的 「抢占上线」：

查询服务端在线设备 → 逐个下线其他设备 → 认证本机 → 接管成功

实测服务端行为（用真实 Token 验证）：

手机在线时，电脑直接认证      → 409 套餐只支持单设备认证
先 logout 手机的 IP          → 200 认证已退出
再 auth 电脑的 IP            → 200 认证成功。   ← 接管成功

所以这条路径是确定可行的，不需要填手机 IP —— 程序会自己查在线列表。

也可以点 「在线设备」 手动操作：

  • 绿点 = 本机，黄点 = 其他设备
  • 点其他设备那行的 「下线这台」，把名额抢过来
  • 点主窗口的 「归还名额」，把位置让回手机

程序默认不会自动顶替手机（设置里的「名额被占时自动顶替手机」默认关闭），

避免莫名其妙把手机挤掉。需要自动抢名额时再去设置里手动打开。

方案 C：看状态卡上的「在线设备」那一行

主窗口状态卡现在会实时显示在线设备，例如：

在线设备   电脑有线 10.135.130.202（本机）
在线设备   手机 WIFI 10.135.130.111

一眼看出名额被谁占着。

单设备限制：手机和电脑不能同时上

云高账号同时只能有一台设备在线。所以：

  • PC 认证会顶掉手机 → 手机上的校园网掉线（必然结果，不是 bug）
  • 手机在 APP 里重新认证，又会把 PC 顶掉，还可能导致 Token 轮换

程序对此做了三件事：

1. 四级认证链，逐级回退

auth?ip=<PC_IP>                    直接认证
   ↓ 失败
logout?ip=<PC_IP> → auth?ip=       清理本机陈旧会话后重试
   ↓ 仍失败（判定名额被占）
logout?ip=<手机IP> → auth?ip=      自动顶替手机（需先填手机 IP）
   ↓ 仍失败
明确报错：区分「Token 已失效」还是「账号被其他设备占用」

2. 自动顶替手机

在设置里填一次手机 IP，之后 PC 认证失败会自动把手机顶下去。

手机 IP 怎么查：手机连上校园网 → Wi-Fi 详情 → 看 IP 地址。

3. 一键归还名额

点 「归还名额」，立刻把位置让回给手机，不用开 APP 操作。

关于共享上网：理论上可以让 PC 做 NAT 把网络共享给手机，但本工具没有实现这个功能，

定位是「PC 独占」。手机需要上网时请用「归还名额」。

遇到问题怎么办

Q：提示「未连接校园网」/「认证接口不可达」

你没连上校园网内网。先连 Wi-Fi，再操作程序。

Q：二维码窗口说「未能解析出二维码内容」

学校升级了认证页面结构。运行日志里应该有具体线索，可以反馈给作者更新。

Q：点「扫码登录」没反应 / 一直转圈

  • 确认已连上校园网（看状态卡的出口 IP 有没有值）
  • 二维码是 10 分钟有效，旧的点「刷新」
  • 试试点「立即认证」看日志报什么

Q：认证成功了但电脑还是上不了网

  • 看状态点是不是绿的。绿点但浏览器打不开网页，可能是 DNS 问题，试试 8.8.8.8 / 114.114.114.114
  • 退出重开浏览器（某些校园网需要重新走一次代理）

Q：扫码登录之后过一会儿又掉线了？

这是预期行为，不是 bug。扫码只是让服务端放行当前这一台设备一次， 会话有有效期。要真正做到"开机就连、断网自愈"， 必须填账号密码（第四步），让程序能自己换 Token。

Q：填账号密码后提示"账号不存在"？

说明你的云高账号不是手机号（可能是学号），或者没在云高平台注册。 改用「扫码登录」+ 抓包取 Token 也能实现自动重连， 只是 Token 被轮换时需要手动重抓一次。

Q：Token 提示失效

两种原因，处理不同：

原因 表现 解决
在 APP 里退出了账号 Token 立刻作废 重新抓一次
发生了设备登录（手机重连） Token 被轮换 重新抓一次（程序会自动续存大部分情况）

不要在糕糕 APP 里退出账号，退出后 Token 立即失效。

Q：每次开机都要手动点一次

勾选「开机自动认证」并点「保存设置」。如果开机自启没生效，检查一下 exe 是否在了一个之后可能会被移动/删除的目录。

Q：想换个学校用

改设置里的认证网关主机和端口，保存后重启程序。本工具不硬编码任何学校信息。

Q：exe 被杀毒软件误报

PyInstaller 单文件程序常见的误报（SmartScreen 信誉问题，非中毒）。 最省事的做法：点「更多信息」→「仍要运行」。程序本身开源，全部代码可查； 需要彻底消除告警请看 docs/Defender-误报排查.md（推荐用目录版，误报率最低）。

Q：Token 安全吗

Token 用 Windows DPAPI（系统级、用户绑定）加密后存在 %LOCALAPPDATA%\GaoGaoNetAUTO\config.json 里：

  • 文件里是密文，不是明文（手机号、密码同样加密）
  • 换一台电脑 / 换用户，密文解不开
  • 复制别人的 config.json 到你电脑上也没用
  • 目录权限已收紧，同机其他账号读写不了

进阶玩法

Token 寿命实验

想知道「你这所学校到底轮不换 Token」？在源码目录运行：

python tools/tokenlab.py

它会：Token 认证一次 → 让你在手机上做一次设备登录 → 再用同一 Token 认证 → 直接给出「轮换 / 不轮换」的结论。

打包版里没有独立的 tools/tokenlab.py，需要在源码目录用命令行跑。

主窗口设置区也有一个「Token 寿命实验」按钮会帮你调起它。

抓取模式（分析用）

想研究网页扫码流程的真实请求：

pip install playwright
python -m playwright install chromium
python tools/capture.py

会输出 capture.json（完整请求记录）和 capture.log（人读摘要）。

结论预告：实测已确认页面里根本没有状态轮询接口，

手机确认后服务端直接改写「该 session 对应 IP」的上线状态。

所以本工具判定「授权完成」的信号是本机是否已连通外网。

从源码运行 / 自己打包

pip install -r requirements.txt
python main.py          # 直接跑
python tools/build_exe.py     # 打包成 exe

附：配置文件说明

config.json 生成在 %LOCALAPPDATA%\GaoGaoNetAUTO\（与 exe 位置无关），长这样：

{
  "host": "hgs.auth.yungao-tech.com",
  "port": 1110,
  "phone_ip": "",
  "token": "dpapi:...(加密后的密文)",
  "autostart": true,
  "auto_kick_phone": true,
  "last_ip": "10.135.130.202",
  "last_auth_ok": true
}
字段 说明
host / port / scheme 认证网关地址，换学校改这三个；必须在白名单内（hgs.auth.yungao-tech.com / user.v4.yungao-tech.com），否则程序会拒绝保存并拒绝发送 Token
phone_ip 手机 IP，用于自动顶替
token 加密后的 Token（dpapi: 前缀表示 DPAPI 格式，v3x: 表示降级加密格式）
token_prev 上一版 Token，续存失败时回退用
account_mobile / account_password 云高账号手机号与密码，均加密存储
autostart 开机自动认证开关
auto_kick_phone 名额被占时自动顶替手机（默认关）
wlan_acname / paip / vlan 接入点参数，多数学校不用改
last_ip / last_auth_ok 上次认证的出口 IP 与结果，用于判断 IP 是否漂移

同目录还有 config.json.bak（自动备份）、logs/app.log（脱敏后的运行日志）。

想彻底重来就点设置区的「清除已保存凭据」。

手改配置前先关掉程序（托盘图标右键 → 退出），否则退出时会把内存里的值写回去覆盖你的修改。

一句话总结

你的目标 怎么做
现在就要上网 连校园网 → 「扫码登录」→ 扫一下
以后彻底不掏手机 抓一次 Token → 填进去 → 勾选开机自启
手机和电脑都想上 用「归还名额」来回切
学校换了网关 设置里改主机和端口
出问题了 看「运行日志」，红色行后面写的就是原因
