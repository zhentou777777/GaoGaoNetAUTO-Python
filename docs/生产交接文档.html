第 1 部分 · 使用者指南

1.1 三十秒速览

这个程序做一件事：让你的电脑在校园网下自动完成认证，并一直保持在线。

  • 开机 → 自动认证，不用点任何按钮
  • 网断了 → 自己重连，指数退避 15/30/60/120 秒
  • 不需要掏手机扫码（配一次账号密码就永久免扫码）
  • 不会把你手机踢下线（走热点共享时电脑和手机同一出口 IP）

1.2 三种安装形态怎么选

形态 文件 需要装 Python Defender 被拦概率 推荐场景
A. 目录版（推荐） GaoGaoNetAUTO-ondir.zip 否 最低 第二台电脑、有杀软的机器
B. 单文件版 GaoGaoNetAUTO.exe 否 较高 习惯单文件、能处理拦截
C. 源码绿色包 GaoGaoNetAUTO-portable.zip 是 最低 想改代码 / 无杀软环境

A. 目录版（主推）

  1. 解压 GaoGaoNetAUTO-ondir.zip 到任意目录（建议 D:\Tools\GaoGaoNetAUTO）。
  2. 先解除下载锁定（否则 Defender 仍会拦）：

``powershell Get-ChildItem -Recurse -Include *.exe,*.dll,*.pyd | Unblock-File `` 或右键 exe → 属性 → 底部勾选「解除锁定」→ 确定。

  1. 双击 GaoGaoNetAUTO.exe。
  2. 首次运行会自动创建配置目录 C:\GaoGaoNetAUTO\。

B. 单文件版

直接双击 GaoGaoNetAUTO.exe。若被 Defender 拦，见 1.9 杀软拦截处置。

C. 源码绿色包

  1. 解压。
  2. 双击 setup.bat（建虚拟环境并装依赖，wheels/ 存在时走离线安装）。
  3. 双击 run.bat 启动。

stop.bat 用于结束残留进程，避免重复开多个实例。

1.3 配置目录约定

程序的所有配置与运行时文件统一放在 C:\GaoGaoNetAUTO\：

C:\GaoGaoNetAUTO\
├── config.json        主配置（Token、账号密码等）
├── config.json.bak    自动备份
├── assets\            程序图标
├── qr_tmp.png         扫码窗口的临时二维码
└── logs\              运行日志

要点：

  • 与 exe 所在位置无关。exe 放桌面、放 D 盘、放 C:\Program Files\ 都一样。
  • 换机器/重装 exe 不会丢配置（配置不在 exe 旁边）。
  • 旧版本（配置在 exe 同目录）首次运行时自动迁移一次，原文件保留不动。
  • 想改位置：设环境变量 GAOGAO_DATA_DIR（如 D:\GaoGaoData）。

1.4 首次配置（三种方式，任选其一）

方式 1：账号密码（推荐，一次配置永久免扫码）

  1. 点右上角 「设置」。
  2. 在「账号密码登录」区填手机号和密码，点 「登录并保存」。
  3. 提示登录成功即完成。程序会自动换取并保存 Token。
  4. 之后 Token 失效时会自动用账号密码换新的，不用再管。

密码与 Token 一样加密存储，不落盘明文。日志里手机号显示为 131****2536。

若云高侧该账号被要求图形/短信验证码，本路径会失败，改用方式 2。

方式 2：扫码登录（无账号密码时）

  1. 点主界面 「扫码登录」。
  2. 窗口里会显示二维码（本地生成，不依赖 APP 页面）。
  3. 用手机 APP 扫这个码。
  4. 扫码成功后 Token 自动保存。二维码 10 分钟有效，过期点「刷新」。

方式 3：手工填 Token（抓包法）

  1. 点 「怎么获取？」 看图文步骤（需抓包工具）。
  2. 拿到 Authorization: Bearer xxxxx 里的那串，粘进设置框。
  3. 点 「校验并保存」，校验通过即保存。

Token 形如 v1:... 的是本程序加密后的格式；直接填明文 Token 也能正常读取（程序自动识别）。

1.5 日常使用

主界面 6 个操作按钮：

按钮 作用 什么时候用
立即认证 主动认证上线（会抢占占用名额的设备） 需要马上上网、且确定手机可以先断
扫码登录 打开扫码窗口 没有 Token、Token 失效且没配账号密码
抢占上线 主动下线对方设备并接管 手机占着名额但你想让电脑上
在线设备 查看当前在线设备列表，可单台下线 想知道是谁占着名额
归还名额 下线本机，把名额还给手机 要把网络让回手机
检查 Token 体检 Token 是否还有效 怀疑 Token 过期

状态卡上会实时显示：本机出口 IP、Token 状态、自愈状态条、在线设备摘要。

托盘图标（需要 pystray）右键菜单：显示主窗口 / 立即认证 / 退出。

1.6 开机自启

  • 设置面板里有「开机自启」勾选框，勾上即生效。
  • 实现方式：往启动文件夹写一个 GaoGaoNetAUTO.cmd

（%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\）。 选它而不是写注册表 Run 键，是因为后者容易被杀毒软件判为「可疑自启动」。

  • 开机后程序会延迟 8 秒再认证（等网络协商完成）。
  • 关闭自启：取消勾选即可，.cmd 会被删除。

1.7 断网自动重连

  • 守护线程每 20 秒探测一次外网连通性（TCP 连接 223.5.5.5:53 等四个目标，不发应用层流量）。
  • 连续 2 次失败才判定为断网（避免瞬时抖动误触发）。
  • 断网后进入重连循环，退避间隔 15s → 30s → 60s → 120s（封顶）。
  • 出口 IP 变化（校园网重分配地址）也会触发重新认证。

重连永不抢占：自动重连只做非抢占式认证，不会踢掉手机。只有你手动点「立即认证」或「抢占上线」才会踢。

1.8 与手机共存的正确姿势

单设备套餐下，电脑和手机默认互斥。三种方案：

方案 做法 效果
A. 热点共享（最推荐） 电脑连手机热点，手机先认证上网 两者同一出口 IP，电脑被识别为已在线，完全不互踢
B. 抢占独占 需要电脑独占时点「抢占上线」 对方被下线，电脑接管
C. 让回手机 点「归还名额」 本机下线，名额还给手机

方案 A 下程序会识别为「共享模式：检测到本机已在线」并跳过认证，因此不会因为重复认证把手机挤掉。

1.9 杀软拦截处置

Windows Defender 上最常见的两种拦截：

症状一：下载后文件「不见了」/ 被隔离

  1. 打开 Windows 安全中心 → 病毒和威胁防护 → 保护历史记录。
  2. 找到被拦项 → 操作 → 允许在设备上（若在隔离区，先 还原 再允许）。
  3. 解压后执行：

``powershell Get-ChildItem -Recurse -Include *.exe,*.dll,*.pyd | Unblock-File ``

症状二：运行弹出「Windows 已保护你的电脑」

  1. 点 「更多信息」 → 底部 「仍要运行」 → 「是」。
  2. 若公司/学校策略禁用了该按钮，请 IT 添加排除项：

``powershell Add-MpPreference -ExclusionPath "D:\Tools\GaoGaoNetAUTO" ``

让「发布者」不再显示「未知」

导入随包提供的 GaoGaoNetAUTO.cer（管理员 PowerShell）：

Import-Certificate -FilePath .\GaoGaoNetAUTO.cer -CertStoreLocation Cert:\LocalMachine\Root
Import-Certificate -FilePath .\GaoGaoNetAUTO.cer -CertStoreLocation Cert:\LocalMachine\TrustedPublisher

自签名证书不能消除 SmartScreen 的信誉拦截，只能消除「未知发布者」外观。根治需要正规 OV / Azure Trusted Signing 证书。

1.10 FAQ

Q1：点「立即认证」提示成功，但还是不能上网？ 先确认连的是校园网（不是家里 Wi-Fi）。若认证返回的是 HTML 或被重定向，界面会提示「请确认已连接校园网」。也可能是网关地址不对，检查设置里的 host/port。

Q2：提示「套餐只支持单设备认证，已有设备在线」？ 说明名额被别的设备占着。点「在线设备」看是谁，然后二选一：点「抢占上线」接管，或点「归还名额」让回手机，或改走热点共享。

Q3：提示「Token 已失效」？ 如果配了账号密码，程序会自动换新 Token，等几秒再看状态卡。若没配，去设置里补账号密码，或用「扫码登录」重新来一次。

Q4：电脑和手机还是互相踢？ 检查是不是手动点了「立即认证」——这个按钮会抢占。如果不想踢手机，就不要点它，改用热点共享模式；程序自动重连本身不会踢。

Q5：开机没有自动认证？ ① 设置里「开机自启」是否勾选；② 启动文件夹里是否有 GaoGaoNetAUTO.cmd；③ 程序是否已配置 Token 或账号密码（两者都没有时开机不会自动动作）。

Q6：状态卡显示「共享模式」是什么意思？ 说明本机出口 IP 已在服务端在线列表中（通常是你经手机热点共享），程序判定为已在线并跳过了认证，属正常。

Q7：二维码一直显示「已过期」？ 点「刷新」重新生成。二维码有效期 10 分钟。

Q8：日志里出现大量 410？ Token 已失效且没能自动换新。检查设置里账号密码是否正确。

Q9：想把配置清空重来？ 删掉 C:\GaoGaoNetAUTO\config.json（或整个 C:\GaoGaoNetAUTO\ 目录），重启程序。

Q10：换电脑后 Token 失效？ Token 用机器指纹加密，换机解不开，属预期。请在新机上重新配账号密码或扫码。

Q11：托盘图标没有？ 未安装 pystray / Pillow。程序会正常显示主窗口，日志提示已跳过托盘。

Q12：程序在 C:\Program Files\ 下能跑吗？ 能。配置写在 C:\GaoGaoNetAUTO\，不需要 exe 目录可写。

1.11 卸载

  1. 设置里取消「开机自启」（或手动删启动文件夹的 GaoGaoNetAUTO.cmd）。
  2. 删除 exe 与整个解压目录。
  3. 删除 C:\GaoGaoNetAUTO\（含 config.json 里的 Token 与账号密码）。
  4. 如导入过证书：证书 → 受信任的根证书颁发机构 删除 GaoGaoNetAUTO。

2.3 运行流程

启动
 │
 ├─ 读配置 config.json（Token / 账号密码 / 开关）
 ├─ 初始化托盘（pystray 缺失则跳过）
 ├─ _startup_checks()
 │    ├─ 有 Token？→ 后台 check_token（体检，不改变在线状态）
 │    ├─ 有 Token 且开了自启？→ 延迟 8s → 认证
 │    ├─ 无 Token 但有账号密码？→ 延迟 8s → 认证（内部会先换 Token）
 │    └─ 都没有 → 提示先扫码
 │
 ├─ 启动 NetGuard 守护线程（先 sleep 3s）
 │    └─ 每 20s：探测外网 + 检测出口 IP 变化

 │
 └─ 用户交互（按钮 / 托盘菜单）
      ├─ 立即认证 → login_chain(takeover=True)   ← 会抢占
      ├─ 抢占上线 → login_chain(takeover=True)   ← 会抢占
      ├─ 归还名额 → logout 本机
      └─ 自动重连 → login_chain(takeover=False)  ← 不抢占

2.4 认证链与 takeover 语义

login_chain(ip, token, phone_ip, kick_phone, takeover)
 │
 ├ 0) 共享模式：查 /api/network/online
 │      若本机 ip 已在列表 → 直接 OK（★ 绝不 logout，这是"不挤手机"的根因）
 │
 ├ 1) 直连      auth?ip=
 ├ 2) 清陈旧会话 logout(ip) → auth?ip=
 ├ 3) 自动抢占（仅 takeover=True）→ 逐个 logout 其它设备 → auth?ip=
 ├ 4) 顶替手机（kick_phone 且填了 phone_ip）→ logout(phone_ip) → auth?ip=
 └ 5) 明确归因：TOKEN_INVALID / DEVICE_LIMIT / NOT_AUTH 分别给出可操作提示

takeover 是本项目最关键的一个参数。

- True = 用户主动要求独占（点了「立即认证」或「抢占上线」），可以踢别人。

- False = 自动重连，绝不踢。

若守护线程的重连也踢，手机 APP 与电脑会互相顶，形成无限循环 —— 这正是早期用户反馈「手机和电脑还是会抢登录」的根因。

2.5 四层自愈

层 触发 动作 依赖
L0 认证失败且判定 Token 失效 POST /api/login 换新 Token → 重跑认证链 acclogin.py
L1 服务端在响应体/响应头下发了新 Token 提取并自动续存（旧 Token 存 token_prev） auth.py _extract_new_token
L2 Token 拿不到但用户在场 降级扫码（本地渲染二维码） qrflow.py
L3 全失败 提示重新抓包（「怎么获取？」有图文步骤） —

闭环成立的关键：只有 L0 能自己换到一个新 Token，才叫真正的自愈；光重放旧 Token 在服务端轮换后会一直失败。

2.6 数据与安全

机器指纹 (Windows: HKLM\SOFTWARE\Microsoft\Cryptography\MachineGuid)
        │  失败退化为 node|machine|login
        ▼
SHA-256("gaogao-token-enc|" + seed) → 加密密钥
SHA-256("gaogao-token-mac|" + seed) → MAC 密钥
        │
        ├─ 加密：cipher = plaintext XOR keystream(key, len)
        │          keystream = SHA-256(key || counter_be32) 逐块拼接
        │          tag = HMAC-SHA256(mac_key, cipher)[:16]
        │          落盘 = "v1:" + base64(cipher + tag)
        │
        └─ 解密：先验 HMAC（compare_digest 常量时间比较）→ 再 XOR → utf-8
                   非 "v1:" 前缀 → 当作手工填写的明文直接返回

设计要点：

  • 完整性优先：HMAC 校验失败一律返回空，不做解密尝试。
  • 换机失效：密钥绑机器指纹，拷贝 config.json 到别的机器解不出 Token → 多机部署用账号密码。
  • 不落明文：Token 与账号密码均加密；手机号明文（已知遗留 L7）。
  • 日志不泄密：手机号脱敏 131****2536；Token 不进日志。

3.4 签名与发布流程（自签名）

目的：消除「未知发布者」外观，并让签名长期有效。

前提：自签名不能让 SmartScreen 直接放行（见 1.9）。

步骤 1：生成代码签名证书（Administrator PowerShell）

$pw = ConvertTo-SecureString -String "<你的口令>" -Force -AsPlainText
New-SelfSignedCertificate -Type CodeSigningCert -Subject "CN=GaoGaoNetAUTO" `
  -FriendlyName "GaoGaoNetAUTO" -CertStoreLocation Cert:\CurrentUser\My `
  -NotAfter (Get-Date).AddYears(10) `
  -TextExtension @("2.5.29.37={text}1.3.6.1.5.5.7.3.3") `
  -Password $pw

2.5.29.37={text}1.3.6.1.5.5.7.3.3 是 Extended Key Usage = Code Signing，缺它 Windows 不认这是代码签名证书。

导出 PFX（供后续签名）与 CER（供目标机导入）：

$cert = Get-ChildItem Cert:\CurrentUser\My | Where-Object { $_.Subject -like "*GaoGaoNetAUTO*" }
Export-PfxCertificate -Cert $cert -FilePath .\sign\GaoGaoNetAUTO.pfx -Password $pw
Export-Certificate  -Cert $cert -FilePath .\sign\GaoGaoNetAUTO.cer

.pfx 含私钥，不入库（.gitignore 已忽略 sign/*.pfx）。

步骤 2：签名 exe

$signtool = "C:\Program Files (x86)\Windows Kits\10\bin\x64\signtool.exe"
& $signtool sign /fd SHA256 /td SHA256 `
  /f .\sign\GaoGaoNetAUTO.pfx /p "<口令>" `
  /tr http://timestamp.digicert.com /ts http://timestamp.digicert.com `
  .\dist\GaoGaoNetAUTO.exe
  • /fd SHA256 /td SHA256：签名算法与摘要算法。
  • /tr + /ts：可信时间戳。保证证书过期后签名依然有效 —— 这是「签名有效性」的关键，务必带上。
  • 也可用脚本：tools/sign_release.ps1（计划新增）。

步骤 3：验证

Get-AuthenticodeSignature .\dist\GaoGaoNetAUTO.exe |
  Format-List Status, StatusMessage, SignerCertificate, TimeStamperCertificate

期望：Status = Valid（本机已信任该自签证书时）。在未导入证书的机器上会是 UnknownError / NotTrusted —— 正常，需先导入 .cer。

步骤 4：正规证书（根治下载即被拦）

唯一能根治 SmartScreen 信誉的是受信任的代码签名证书：

类型 价格 效果
OV 代码签名证书（个人/公司） 约 $100–400/年 SmartScreen 直接放行
Azure Trusted Signing 约 $10–20/年 同上，按次计费
自签名 0 只消除「未知发布者」，SmartScreen 仍需手动绕过

采购后替换步骤 1、2 即可（signtool /tr 指向 CA 的时间戳服务）。

4.3 开机自启机制

项 值
实现 启动文件夹写 GaoGaoNetAUTO.cmd（计划从注册表 Run 迁移）
路径 %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\
命令 @start "" "<exe路径>" --silent
延迟 启动后 8 秒再认证
源码模式 用 pythonw.exe（无黑窗）
卸载 取消勾选即删除 .cmd

为什么不用注册表 Run：Software\Microsoft\Windows\CurrentVersion\Run 是 Defender 行为规则的高危命中点（T1547.001），配合「自启 + 网络 + 凭据」的整体行为容易被 ML 归类为 persistence + credential access。写启动文件夹是纯文件操作，权重低得多，开机自启效果完全等价。

4.4 多机部署注意

  1. 不要拷贝 config.json：Token 用机器指纹加密，拷过去解不开。
  2. 统一用账号密码：每台机各配一次账号密码，Token 失效可自行续期，不依赖人工。
  3. 网关参数统一：host/port 相同，只改账号密码。
  4. 在线设备互斥：同一账号只能一台在线（套餐限制）。多台机器需要错峰或各用各的账号。
  5. 配置目录各自独立：C:\GaoGaoNetAUTO\ 是本机路径，不会跨机同步。

附录 E · 术语表

术语 含义
Token 云高认证的身份凭证，Authorization: Bearer <token>，服务端唯一认定
code / str 网页流程里传参用的一次性授权载体，标明「这次授权给哪台设备」
出口 IP 本机通往认证网关所走的 IP，服务端按它记录在线设备
共享模式 本机出口 IP 已在服务端在线列表中（典型：经手机热点），判定为已在线且不执行下线
抢占（takeover） 用户主动下线占用名额的设备并接管；自动重连永不抢占
自愈 Token 失效后程序自行换新 Token 并重试，无需人工
NAT 模式 本机处于路由器/手机热点之后，出口 IP 与本机 IP 不同
幂等拒绝 已在线的 IP 重复认证仍返回 409，不会重复放行
MOTW Mark-of-the-Web，下载文件带的来源标记，是「下载即被拦」的根因之一
SmartScreen Windows 的应用信誉检查，未签名/低下载量文件易被拦
UPX 常见的 PE 压缩壳，被 Defender 视为高权重可疑特征
HMAC 带密钥的消息认证码，用于校验密文完整性
keystream 由密钥与计数器派生出的伪随机字节流，用于流式加密
