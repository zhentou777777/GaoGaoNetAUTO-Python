## 第 1 部分 · 使用者指南

### 1.1 三十秒速览

这个程序做一件事：**让你的电脑在校园网下自动完成认证，并一直保持在线。**

- 开机 → 自动认证，不用点任何按钮
- 网断了 → 自己重连，指数退避 15/30/60/120 秒
- 不需要掏手机扫码（配一次账号密码就永久免扫码）
- **不会把你手机踢下线**（走热点共享时电脑和手机同一出口 IP）

### 1.2 三种安装形态怎么选

| 形态 | 文件 | 需要装 Python | Defender 被拦概率 | 推荐场景 |
|---|---|---|---|---|
| **A. 目录版（推荐）** | `GaoGaoNetAUTO-v1.0.0-免安装.zip` | 否 | **最低** | 第二台电脑、有杀软的机器 |
| B. 单文件版 | `GaoGaoNetAUTO-v1.0.0-单文件.zip` | 否 | 较高 | 习惯单文件、能处理拦截 |
| C. 源码绿色包 | `GaoGaoNetAUTO-v1.0.0-源码绿色包.zip` | 是 | 最低 | 想改代码 / 无杀软环境 |

#### A. 目录版（主推）

1. 解压 `GaoGaoNetAUTO-v1.0.0-免安装.zip` 到任意目录（建议 `D:\Tools\GaoGaoNetAUTO`）。
2. **先解除下载锁定**（否则 Defender 仍会拦）：
   ```powershell
   Get-ChildItem -Recurse -Include *.exe,*.dll,*.pyd | Unblock-File
   ```
   或右键 exe → 属性 → 底部勾选「解除锁定」→ 确定。
3. **导入签名证书**（**可选**，仅当 exe 被拦且需要显示「已信任」时）：
   ```powershell
   # 管理员 PowerShell —— 只导入到 TrustedPublisher，不要导入 Root
   Import-Certificate -FilePath .\GaoGaoNetAUTO-sign.cer -CertStoreLocation Cert:\LocalMachine\TrustedPublisher
   ```
   > ⚠️ **不要导入 `Cert:\LocalMachine\Root`**（根证书库）——自签名证书进根库等于给这台机器装了一个可签任意代码的根，风险远大于收益。
   > 默认路径其实是：双击 exe → 点「更多信息」→「仍要运行」，**无需动证书库**。
4. 双击 `GaoGaoNetAUTO.exe`。
5. 首次运行会自动创建配置目录 `%LOCALAPPDATA%\GaoGaoNetAUTO\`。

#### B. 单文件版

解压后双击 `GaoGaoNetAUTO.exe`（同目录也会带 `GaoGaoNetAUTO-sign.cer`，导入方式同 A）。
若被 Defender 拦，见 [1.9 杀软拦截处置](#19-杀软拦截处置)。

#### C. 源码绿色包

1. 解压。
2. 双击 `setup.bat`（建虚拟环境并装依赖，`wheels/` 存在时走离线安装）。
3. 双击 `run.bat` 启动。

> `stop.bat` 用于结束残留进程，避免重复开多个实例。

### 1.3 配置目录约定

程序的所有配置与运行时文件统一放在 **`%LOCALAPPDATA%\GaoGaoNetAUTO\`**
（Windows 标准应用数据目录，默认 `C:\Users\<用户名>\AppData\Local\GaoGaoNetAUTO\`）：

```
%LOCALAPPDATA%\GaoGaoNetAUTO\
├── config.json        主配置（Token、账号密码等，全部为 DPAPI 密文）
├── config.json.bak    自动备份
├── assets\            程序图标
├── qr_tmp.png         扫码窗口的临时二维码
└── logs\              运行日志（app.log，自动脱敏 + 轮转）
```

要点：

- **与 exe 所在位置无关**。exe 放桌面、放 D 盘、放 `C:\Program Files\` 都一样。
- 换机器/重装 exe **不会丢配置**（配置不在 exe 旁边）。
- **目录 ACL 已收紧**到「当前用户 + SYSTEM + Administrators」并断开权限继承，
  同机的其他账号读不到配置内容。
- 旧版本（`C:\GaoGaoNetAUTO\` 或 exe 同目录）首次运行时**自动迁移**一次，
  迁移时凭据会用 **DPAPI 重新加密**，不是把旧的混淆密文原样搬过去。
- 想改位置：设环境变量 `GAOGAO_DATA_DIR`（如 `D:\GaoGaoData`）。
- 想清空凭据：设置区点 **「清除已保存凭据」**（含备份文件一起抹掉）。

### 1.4 首次配置（三种方式，任选其一）

#### 方式 1：账号密码（推荐，一次配置永久免扫码）

1. 点右上角 **「设置」**。
2. 在「账号密码登录」区填**手机号**和**密码**，点 **「登录并保存」**。
3. 提示登录成功即完成。程序会自动换取并保存 Token。
4. 之后 Token 失效时会自动用账号密码换新的，**不用再管**。

> 密码与 Token 一样加密存储，不落盘明文。日志里手机号显示为 `131****2536`。
> 若云高侧该账号被要求图形/短信验证码，本路径会失败，改用方式 2。

#### 方式 2：扫码登录（无账号密码时）

1. 点主界面 **「扫码登录」**。
2. 窗口里会显示二维码（**本地生成**，不依赖 APP 页面）。
3. 用手机 APP 扫这个码。
4. 扫码成功后 Token 自动保存。二维码 **10 分钟**有效，过期点「刷新」。

#### 方式 3：手工填 Token（抓包法）

1. 点 **「怎么获取？」** 看图文步骤（需抓包工具）。
2. 拿到 `Authorization: Bearer xxxxx` 里的那串，粘进设置框。
3. 点 **「校验并保存」**，校验通过即保存。

> Token 形如 `v1:...` 的是本程序加密后的格式；直接填**明文** Token 也能正常读取（程序自动识别）。

### 1.5 日常使用

主界面 6 个操作按钮：

| 按钮 | 作用 | 什么时候用 |
|---|---|---|
| **立即认证** | 主动认证上线（**会抢占**占用名额的设备） | 需要马上上网、且确定手机可以先断 |
| **扫码登录** | 打开扫码窗口 | 没有 Token、Token 失效且没配账号密码 |
| **抢占上线** | 主动下线对方设备并接管 | 手机占着名额但你想让电脑上 |
| **在线设备** | 查看当前在线设备列表，可单台下线 | 想知道是谁占着名额 |
| **归还名额** | 下线本机，把名额还给手机 | 要把网络让回手机 |
| **检查 Token** | 体检 Token 是否还有效 | 怀疑 Token 过期 |

状态卡上会实时显示：**本机出口 IP**、**Token 状态**、**自愈状态条**、**在线设备摘要**。

托盘图标（需要 `pystray`）右键菜单：**显示主窗口 / 立即认证 / 开机自启 / 退出**。

### 1.5.1 任务栏占用控制

程序**只占系统托盘一个位置**，不会在任务栏上散落一堆图标：

| 场景 | 表现 | 实现 |
|---|---|---|
| 重复双击 exe | 只弹一次，第二次直接把已有窗口顶到前台后退出 | `taskbar.py` 命名 Mutex 单实例锁（`Local\GaoGaoNetAUTO_SingleInstance_v1`） |
| 开机自启撞上已在跑的实例 | 静默退出，**不弹窗、不抢焦点** | `--silent` 分支跳过 `activate_existing_instance()` |
| 静默模式运行 | 主窗口 `withdraw`，任务栏无任何按钮 | `App.__init__` 的 `silent` 分支 |
| 扫码 / 在线设备 / Token 帮助窗口 | 只作为主窗口的附属窗，**不另起任务栏按钮** | `set_tool_window()` 设 `WS_EX_TOOLWINDOW` |
| 任务栏图标分组 | 独立分组，不和 python.exe 宿主混在一起 | `SetCurrentProcessExplicitAppUserModelID` |
| 标题栏 / 任务栏图标 | 显示应用自己的图标，不是 tkinter 默认图标 | `iconphoto` + `iconbitmap` |

> 单实例锁是**跨进程**的（Windows 命名 Mutex），所以从任务栏、快捷方式、
> 启动文件夹 `.cmd` 各种方式启动都只会有一份在跑，托盘永远只有一个图标。

### 1.6 开机自启

- **设置面板**里有「开机自启」勾选框，勾上即生效。
- 实现方式：往**启动文件夹**写一个 `GaoGaoNetAUTO.cmd`
  （`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\`）。
  选它而不是写注册表 Run 键，是因为后者容易被杀毒软件判为「可疑自启动」。
- 开机后程序会**延迟 8 秒**再认证（等网络协商完成）。
- 关闭自启：取消勾选即可，`.cmd` 会被删除。

### 1.7 断网自动重连

- 守护线程每 **20 秒**探测一次外网连通性（TCP 连接 `223.5.5.5:53` 等四个目标，不发应用层流量）。
- **连续 2 次**失败才判定为断网（避免瞬时抖动误触发）。
- 断网后进入重连循环，退避间隔 **15s → 30s → 60s → 120s**（封顶）。
- 出口 IP 变化（校园网重分配地址）也会触发重新认证。

> **重连永不抢占**：自动重连只做非抢占式认证，不会踢掉手机。只有你手动点「立即认证」或「抢占上线」才会踢。

### 1.8 与手机共存的正确姿势

单设备套餐下，电脑和手机默认**互斥**。三种方案：

| 方案 | 做法 | 效果 |
|---|---|---|
| **A. 热点共享（最推荐）** | 电脑连**手机热点**，手机先认证上网 | 两者同一出口 IP，电脑被识别为已在线，**完全不互踢** |
| **B. 抢占独占** | 需要电脑独占时点「抢占上线」 | 对方被下线，电脑接管 |
| **C. 让回手机** | 点「归还名额」 | 本机下线，名额还给手机 |

> 方案 A 下程序会识别为「共享模式：检测到本机已在线」并**跳过认证**，因此不会因为重复认证把手机挤掉。

### 1.9 杀软拦截处置

Windows Defender 上最常见的两种拦截：

#### 症状一：下载后文件「不见了」/ 被隔离

1. 打开 **Windows 安全中心** → **病毒和威胁防护** → **保护历史记录**。
2. 找到被拦项 → **操作** → **允许在设备上**（若在隔离区，先 **还原** 再允许）。
3. 解压后执行：
   ```powershell
   Get-ChildItem -Recurse -Include *.exe,*.dll,*.pyd | Unblock-File
   ```

#### 症状二：运行弹出「Windows 已保护你的电脑」

1. 点 **「更多信息」** → 底部 **「仍要运行」** → **「是」**。
2. 若公司/学校策略禁用了该按钮，请 IT 添加排除项（**精确到 exe 文件**，不要排除整个目录）：
   ```powershell
   Add-MpPreference -ExclusionPath "D:\Tools\GaoGaoNetAUTO\GaoGaoNetAUTO.exe"
   ```
   > ❌ 不要写 `-ExclusionPath "D:\Tools\GaoGaoNetAUTO"`（整目录）——那等于给整个目录开免检，范围过大。

#### 让「发布者」不再显示「未知」

导入随包提供的 `GaoGaoNetAUTO-sign.cer`（**管理员** PowerShell）：

```powershell
# 只导入 TrustedPublisher，不要导入 Root
Import-Certificate -FilePath .\GaoGaoNetAUTO-sign.cer -CertStoreLocation Cert:\LocalMachine\TrustedPublisher
```

> ⚠️ **不要导入根证书库**（`Cert:\LocalMachine\Root`）——自签名证书进根库等于给这台机器装了一个可签任意代码的根，风险远大于收益。
>
> 自签名证书**不能**消除 SmartScreen 的信誉拦截，只能消除「未知发布者」外观。根治需要正规 OV / Azure Trusted Signing 证书。

#### 误报申诉

先抄下检测名（保护历史记录里可见，如 `PUA:Win32/Packer`），再提交：

### 1.10 FAQ

**Q1：点「立即认证」提示成功，但还是不能上网？**
先确认连的是校园网（不是家里 Wi-Fi）。若认证返回的是 HTML 或被重定向，界面会提示「请确认已连接校园网」。也可能是网关地址不对，检查设置里的 host/port。

**Q2：提示「套餐只支持单设备认证，已有设备在线」？**
说明名额被别的设备占着。点「在线设备」看是谁，然后二选一：点「抢占上线」接管，或点「归还名额」让回手机，或改走热点共享。

**Q3：提示「Token 已失效」？**
如果配了账号密码，程序会自动换新 Token，等几秒再看状态卡。若没配，去设置里补账号密码，或用「扫码登录」重新来一次。

**Q4：电脑和手机还是互相踢？**
检查是不是**手动**点了「立即认证」——这个按钮**会**抢占。如果不想踢手机，就不要点它，改用热点共享模式；程序自动重连本身不会踢。

**Q5：开机没有自动认证？**
① 设置里「开机自启」是否勾选；② 启动文件夹里是否有 `GaoGaoNetAUTO.cmd`；③ 程序是否已配置 Token 或账号密码（两者都没有时开机不会自动动作）。

**Q6：状态卡显示「共享模式」是什么意思？**
说明本机出口 IP 已在服务端在线列表中（通常是你经手机热点共享），程序判定为已在线并跳过了认证，属正常。

**Q7：二维码一直显示「已过期」？**
点「刷新」重新生成。二维码有效期 10 分钟。

**Q8：日志里出现大量 410？**
Token 已失效且没能自动换新。检查设置里账号密码是否正确。

**Q9：想把配置清空重来？**
删掉 `%LOCALAPPDATA%\GaoGaoNetAUTO\config.json`（或整个 `%LOCALAPPDATA%\GaoGaoNetAUTO\` 目录），重启程序。

**Q10：换电脑后 Token 失效？**
Token 用机器指纹加密，换机解不开，属预期。请在新机上重新配账号密码或扫码。

**Q11：托盘图标没有？**
未安装 `pystray` / `Pillow`。程序会正常显示主窗口，日志提示已跳过托盘。

**Q12：程序在 `C:\Program Files\` 下能跑吗？**
能。配置写在 `%LOCALAPPDATA%\GaoGaoNetAUTO\`，不需要 exe 目录可写。

**Q13：任务栏/托盘里出现了好几个「糕糕校园网自动认证」图标？**
那是**旧版本**没有单实例锁，多开了几个。新版（v1.0.0 起）带跨进程单实例锁，
无论从哪启动都只会有一份在跑，托盘只有一个图标。
把旧的实例全部退出（托盘图标右键 → 退出），再用新版本启动即可。

**Q14：关掉主窗口后程序还在跑吗？**
在。关窗口是「最小化到托盘」，守护线程继续工作；
托盘图标右键 → 退出 才真正结束进程。

### 1.11 卸载

1. 设置里取消「开机自启」（或手动删启动文件夹的 `GaoGaoNetAUTO.cmd`）。
2. 删除 exe 与整个解压目录。
3. 删除 `%LOCALAPPDATA%\GaoGaoNetAUTO\`（含 config.json 里的 Token 与账号密码）。
4. 如导入过证书：`证书 → 受信任的根证书颁发机构` 删除 `GaoGaoNetAUTO`。

### 2.3 运行流程

```

 │
 ├─ 设置 AppUserModelID（任务栏独立分组）
 ├─ 取单实例锁
 │    └─ 已被占用 → 把已有窗口顶到前台（--silent 时静默退出）→ 结束
 ├─ 读配置 config.json（Token / 账号密码 / 开关）

 │    ├─ 有 Token 且开了自启？→ 延迟 8s → 认证
 │    ├─ 无 Token 但有账号密码？→ 延迟 8s → 认证（内部会先换 Token）
 │    └─ 都没有 → 提示先扫码
 │
 ├─ 启动 NetGuard 守护线程（先 sleep 3s）
 │    └─ 每 20s：探测外网 + 检测出口 IP 变化
 │         └─ 连续 2 次失败 → 触发重连循环（15/30/60/120s 退避）
 │
 └─ 用户交互（按钮 / 托盘菜单）
      ├─ 立即认证 → login_chain(takeover=True)   ← 会抢占
      ├─ 抢占上线 → login_chain(takeover=True)   ← 会抢占
      ├─ 归还名额 → logout 本机
      └─ 自动重连 → login_chain(takeover=False)  ← 不抢占
```

### 2.4 认证链与 `takeover` 语义

```
login_chain(ip, token, phone_ip, kick_phone, takeover)
 │
 ├ 0) 共享模式：查 /api/network/online
 │      若本机 ip 已在列表 → 直接 OK（★ 绝不 logout，这是"不挤手机"的根因）
 │
 ├ 1) 直连      auth?ip=
 ├ 2) 清陈旧会话 logout(ip) → auth?ip=
 ├ 3) 自动抢占（仅 takeover=True）→ 逐个 logout 其它设备 → auth?ip=
 ├ 4) 顶替手机（kick_phone 且填了 phone_ip）→ logout(phone_ip) → auth?ip=
 └ 5) 明确归因：TOKEN_INVALID / DEVICE_LIMIT / NOT_AUTH 分别给出可操作提示
```

> **`takeover` 是本项目最关键的一个参数。**
> - `True` = 用户**主动**要求独占（点了「立即认证」或「抢占上线」），可以踢别人。
> - `False` = **自动**重连，绝不踢。
>
> 若守护线程的重连也踢，手机 APP 与电脑会互相顶，形成无限循环 —— 这正是早期用户反馈「手机和电脑还是会抢登录」的根因。

### 2.5 四层自愈

| 层 | 触发 | 动作 | 依赖 |
|---|---|---|---|
| **L0** | 认证失败且判定 Token 失效 | `POST /api/login` 换新 Token → 重跑认证链 | `acclogin.py` |
| **L1** | 服务端在响应体/响应头下发了新 Token | 提取并自动续存（旧 Token 存 `token_prev`） | `auth.py` `_extract_new_token` |
| **L2** | Token 拿不到但用户在场 | 降级扫码（本地渲染二维码） | `qrflow.py` |
| **L3** | 全失败 | 提示重新抓包（「怎么获取？」有图文步骤） | — |

**闭环成立的关键**：只有 L0 能**自己换到一个新 Token**，才叫真正的自愈；光重放旧 Token 在服务端轮换后会一直失败。

### 2.6 数据与安全

**凭据加密（现行方案）**

```
明文（Token / 密码 / 手机号）
        │
        ▼  vault.protect()
  Windows DPAPI（CryptProtectData）
    · 系统级、**用户绑定**（换用户解不开）
    · 随机 nonce（由 LSA 生成，非确定性）
    · 自带完整性校验
    · 附加熵 = "GaogaoNetAUTO.CampusAuth.v1"
        │
        ▼  落盘
  "dpapi:" + base64(DPAPI blob)
```

非 Windows 平台走降级方案 `v3x:`（随机 salt + 随机 nonce + HMAC-SHA256），
主密钥存在 sidecar 文件里（权限 0600）。**目标平台是 Windows，永远走 DPAPI 主路径。**

历史格式 `v1:` / `v2:`（旧版「确定性 XOR 混淆」）**仍可解密**，
但读到后会立刻用新方案**重新加密**并落盘 —— 不把旧的混淆密文继续用下去。

设计要点：

- **标准方案替代自拼密码学**：旧版密钥派生自「主机名 + 网卡 MAC + 用户名 + 机型」，
  全是公开信息，任何人都能算出同一把钥匙；新方案交给系统密钥服务。
- **完整性优先**：DPAPI 校验失败返回空，**不做解密尝试**。
- **不落明文**：Token、密码、**手机号**均加密（旧版手机号是明文，已修复）。
- **目录 ACL 收紧**：`%LOCALAPPDATA%\GaoGaoNetAUTO\` 权限限定为
  「当前用户 + SYSTEM + Administrators」并断开继承（纯 ctypes 实现，不起子进程）。
- **可一键清除**：设置区「清除已保存凭据」会抹掉 Token / 密码 / 手机号，
  并覆写删除备份文件。
- **网关白名单**：带 Token 的请求前先校验 `host` / `scheme` / `port`，
  不在白名单内**直接拒绝发送**（防止配置被篡改后把 Token 发到第三方）。
- **日志不泄密**：文件日志自动脱敏（Authorization 头、token/password 字段、
  11 位手机号、长随机串），并按 512KB 轮转保留 3 份。

### 2.7 交付形态与安全加固

### 3.4 签名与发布流程（自签名）

> 目的：消除「未知发布者」外观，并让签名长期有效。
> **前提**：自签名**不能**让 SmartScreen 直接放行（见 1.9）。
> **已实测**：v1.0.0 的两个 exe 形态签名状态均为 `Valid`。

#### 一条命令搞定

```powershell
# 在打包机上执行（当前用户证书库即可，不需要管理员）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\sign_release.ps1 `
    -Path dist\GaoGaoNetAUTO\GaoGaoNetAUTO.exe
```

脚本自动完成：

1. **查找或创建**带 Code Signing EKU 的自签名证书
   （`CN=Gaogao Campus Auth, O=Gaogao Network, L=Guangzhou, S=Guangdong, C=CN`，3 年有效期）
2. **加入本机信任**（`CurrentUser\Root` + `CurrentUser\TrustedPublisher`），
   这样本机校验时能显示 `Valid` 而不是 `UnknownError`
3. **导出** `GaoGaoNetAUTO-sign.pfx`（私钥）+ `GaoGaoNetAUTO-sign.cer`（公钥）
   —— 未显式给密码时自动生成随机密码并写入同目录 `pfx-password.txt`
4. **签名**：优先用 Windows SDK 的 `signtool.exe`（RFC3161 时间戳）；
   没装 SDK 时回退到 PowerShell 的 `Set-AuthenticodeSignature`（Authenticode 时间戳）
5. **校验**并打印签名状态、主题、有效期

也可以打包时一步到位：

```powershell
python build_exe.py --sign
```

> **关键点**
> - `2.5.29.37={text}1.3.6.1.5.5.7.3.3` 是 **EKU = Code Signing**，缺它 Windows 不认这是代码签名证书。
> - **时间戳必带**。没有时间戳，证书 3 年到期后签名直接失效，装到别人机器上照样报「签名无效」。
> - `.pfx`（私钥）与 `pfx-password.txt` **绝不随包分发**。`make_release.py` 已在打包时排除，
>   CI 与发布流程也要守住这条线。

#### 目标机导入证书（管理员 PowerShell，**可选**）

```powershell
# 只导入 TrustedPublisher；不要导入根证书库（风险远大于收益）
Import-Certificate -FilePath .\GaoGaoNetAUTO-sign.cer -CertStoreLocation Cert:\LocalMachine\TrustedPublisher
```

> 默认路径**不需要导入任何证书**：双击 exe →「更多信息」→「仍要运行」即可。
> 导入证书只是让「发布者」不显示「未知」，**不能**消除 SmartScreen 信誉拦截。

导入后验证：

```powershell
Get-AuthenticodeSignature .\GaoGaoNetAUTO.exe |
  Format-List Status, SignerCertificate, TimeStamperCertificate
# Status 应为 Valid
```

#### 手工签名（需要 Windows SDK 时）

```powershell
$signtool = "C:\Program Files (x86)\Windows Kits\10\bin\x64\signtool.exe"
& $signtool sign /fd SHA256 /td SHA256 `
  /f .\GaoGaoNetAUTO-sign.pfx /p "<口令>" `
  /tr http://timestamp.digicert.com /ts http://timestamp.digicert.com `
  .\dist\GaoGaoNetAUTO.exe
```

- `/fd SHA256 /td SHA256`：签名算法与摘要算法。
- `/tr` + `/ts`：**可信时间戳**。保证证书过期后签名依然有效 —— 这是「签名有效性」的关键，务必带上。

#### 正规证书（根治下载即被拦）

唯一能根治 SmartScreen 信誉的是**受信任的代码签名证书**：

| 类型 | 价格 | 效果 |
|---|---|---|
| OV 代码签名证书（个人/公司） | 约 $100–400/年 | SmartScreen 直接放行 |
| EV 代码签名证书 | 约 $300–800/年 | 走线下企业核验，信誉建立最快，硬白名单命中率最高 |
| Azure Trusted Signing | 约 $10–20/年 | 同上，按次计费，最便宜 |
| 自签名 | 0 | 只消除「未知发布者」，SmartScreen 仍需手动绕过 |

采购后替换签名步骤即可（`signtool /tr` 指向 CA 的时间戳服务）。
批量部署建议同时用 `msiexec` / 组策略 / Intune 做静默安装。详见 `docs/Defender-误报排查.md` §6。

### 4.3 开机自启机制

| 项 | 值 |
|---|---|
| 实现 | 启动文件夹写 `GaoGaoNetAUTO.cmd`（**已从注册表 Run 迁移完成**） |
| 路径 | `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\` |
| 命令 | `@start "" "<exe路径>" --silent` |
| 编码 | **GBK**（`.cmd` 由 cmd.exe 读取，UTF-8 会乱码） |
| 属性 | 写入后置为 **Hidden**（不闪黑框） |
| 延迟 | 启动后 8 秒再认证 |
| 源码模式 | 用 `pythonw.exe`（无黑窗） |
| 开关位置 | 设置面板「开机自动认证」勾选框 **+ 托盘右键菜单「开机自启」** |
| 一致性 | `_sync_autostart()` 启动时对账配置与实际文件，防止「以为开了其实没开」 |
| 旧版迁移 | `_migrate_autostart_legacy()` 自动清理注册表里的旧 Run 项并重建 `.cmd` |
| 卸载 | 取消勾选即删除 .cmd |

> 为什么不用注册表 Run：`Software\Microsoft\Windows\CurrentVersion\Run` 是 Defender 行为规则的高危命中点（T1547.001），配合「自启 + 网络 + 凭据」的整体行为容易被 ML 归类为 persistence + credential access。写启动文件夹是纯文件操作，权重低得多，开机自启效果完全等价。
>
> **实测**：升级到 v1.0.0 后，注册表 Run 项已自动清除，启动文件夹出现 `GaoGaoNetAUTO.cmd`（Hidden 属性，0x0002）。

### 4.4 多机部署注意

1. **不要拷贝 `config.json`**：Token 用机器指纹加密，拷过去解不开。
2. **统一用账号密码**：每台机各配一次账号密码，Token 失效可自行续期，不依赖人工。
3. **网关参数统一**：host/port 相同，只改账号密码。
4. **在线设备互斥**：同一账号只能一台在线（套餐限制）。多台机器需要错峰或各用各的账号。
5. **配置目录各自独立**：`%LOCALAPPDATA%\GaoGaoNetAUTO\` 是本机路径，不会跨机同步。

## 附录 A · 接口参数全表

**网关**：`http://{host}:{port}`（默认 `hgs.auth.yungao-tech.com:1110`），请求头 `Authorization: Bearer <token>`。

| 接口 | 方法 | 参数 | 返回 | 用途 |
|---|---|---|---|---|
| `/web/network/code` | GET | `clientip` `clientmac` `wlanacname` `paip` `vlan` | HTML（含 `var code="..."` 与二维码载荷） | 建立扫码会话 |
| `/api/network/auth` | GET | `ip` | JSON | **免扫码认证主路径** |
| `/api/network/auth` | GET | `str` | JSON | 扫码末跳 |
| `/api/network/logout` | GET | `token` `ip` | JSON | 下线某设备 |
| `/api/network/online` | GET | — | JSON `{"data":[{"ip","type"}]}` | 在线设备列表 |
| `/api/network/onestatus` | GET | `ip` | JSON | 某 IP 是否在线 |
| `https://user.v4.yungao-tech.com/api/login` | POST | body `{"mobile","password"}` | JSON `{"code","msg","result":{...}}` | 账号密码换 Token |

`type` 语义：`1`=手机 WIFI，`2`=电脑有线，`3`=电脑 WIFI。

## 附录 E · 术语表

| 术语 | 含义 |
|---|---|
| **Token** | 云高认证的身份凭证，`Authorization: Bearer <token>`，服务端唯一认定 |
| **code / str** | 网页流程里传参用的一次性授权载体，标明「这次授权给哪台设备」 |
| **出口 IP** | 本机通往认证网关所走的 IP，服务端按它记录在线设备 |
| **共享模式** | 本机出口 IP 已在服务端在线列表中（典型：经手机热点），判定为已在线且不执行下线 |
| **抢占（takeover）** | 用户主动下线占用名额的设备并接管；自动重连永不抢占 |
| **自愈** | Token 失效后程序自行换新 Token 并重试，无需人工 |
| **NAT 模式** | 本机处于路由器/手机热点之后，出口 IP 与本机 IP 不同 |
| **幂等拒绝** | 已在线的 IP 重复认证仍返回 409，不会重复放行 |
| **MOTW** | Mark-of-the-Web，下载文件带的来源标记，是「下载即被拦」的根因之一 |
| **SmartScreen** | Windows 的应用信誉检查，未签名/低下载量文件易被拦 |
| **UPX** | 常见的 PE 压缩壳，被 Defender 视为高权重可疑特征 |
| **HMAC** | 带密钥的消息认证码，用于校验密文完整性 |
| **keystream** | 由密钥与计数器派生出的伪随机字节流，用于流式加密 |
